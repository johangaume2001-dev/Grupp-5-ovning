##**Icke-Funktionella Krav

| **Krav ID** | Icke-Funktionellt krav |
|---|---|
| IFK-01 | Spelar kan inte skicka ogiltiga drag via klients request |
| IFK-02 | Spelares personuppgifter skyddas säkert |
| IFK-03 | Systemet kan ej överbelastas via massanrop (Rate-Limiting) |
| IFK-04 | Endast deltagare har åtkomst till aktivt parti |
| IFK-05 | Varje drag valideras mot spelets regler |
| IFK-06 | Speldata lagras säkert enligt GDPR |
| IFK-07 | Spelare kan radera all data kopplad till sitt konto |
| IFK-08 | Data följer GDPR's portabilitet och format krav |
| IFK-09 | Spelare kan återkalla samtycke |
