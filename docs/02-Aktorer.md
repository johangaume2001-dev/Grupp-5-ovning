Aktörerna

1. Spelaren

Den person som spelar Gomoku och konsumerar resultatet av spelet (start, drag, vinst, förlust, oavgjort).

2. Motspelaren ( AI eller Vän)

Den andra personen som deltar i spelet, antingen lokalt eller på distans, och konsumerar samma spelresultat.

3. Systemet som sparar spelet

Ett tekniskt system/komponent som konsumerar spelets tillstånd för att kunna återuppta ett avbrutet parti.


4. Tidsbegränsad användare

En användare som spelar i korta tidsfönster (t.ex. på tunnelbanan) och konsumerar ett snabbt och enkelt flöde.
