# Use Case struktur

- Utgå från aktör
- Skapa UC baserat på ***vad*** aktören vill uppnå. 
- Aktör behöver ej vara person

## Innehåll:

#### Metadata - Tabell
- UC-ID + namn: **UC**-**nr**-bla-bla**.md**
- Version (*läggs till om vi uppdaterar UC*)
- Aktör (*Vid behov skriv även till sekundär aktör*)
- Tillhörande funktionella krav 
- Tillhörande icke-funktionella krav (*om befintligt*)

#### Sektioner
- Description - Förklara UC på en mening
- Precondition - Vad måste stämma innan påbörjat flöde
- Trigger - Hur sätts flödet igång
- Mainflow - Numrerade steg på normala/förväntade flödet
- Postconditions - Vad ska vara sant/falskt efter flödet
- Alternativt flöde - Vad kan gå fel
